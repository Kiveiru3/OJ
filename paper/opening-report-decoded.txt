题目类型（打√选择）设计（√）论文（  ）一、文献综述
　　随着信息技术的快速发展以及高校计算机类专业教学模式的不断改革，程序设计能力已成为衡量学生专业素养和实践能力的重要指标。传统程序设计课程主要依赖人工批改作业或线下实验教学，在教学规模扩大后逐渐暴露出批改效率低、反馈不及时、评价标准主观性强等问题，难以满足当前信息化教学与能力导向培养的需求。在此背景下，基于网络的程序设计在线评测系统逐渐成为高校程序设计教学和竞赛的重要技术支撑平台。
　　在线程序设计评测系统（Online Judge，OJ）通常集成了在线编程、自动评测、成绩反馈与排名展示等功能，能够对学生提交的程序代码进行自动编译、运行和结果判定。钟耀章、桂琼在《ACM竞赛在线测评系统设计与实现》中指出，基于在线评测机制的系统能够有效支撑程序设计竞赛，对提高评测效率和保证评测公平性具有重要意义[1]。该研究为程序设计评测系统在竞赛场景下的应用提供了实践依据。
　　随着 Web 技术的发展，Spring Boot 与 Vue 等前后端分离技术逐渐被引入到教学与评测系统的开发中。安宇鑫在《基于 Spring Boot + Vue 的教学评价专家抽课系统的设计与实现》中表明，Spring Boot 框架在系统开发中具有配置简洁、开发效率高和可维护性强等优势，结合 Vue 前端技术能够有效提升系统的交互性与用户体验[2]。该技术架构为程序设计评测系统的实现提供了良好的技术参考。
　　在程序设计在线评测方向，已有研究针对具体编程语言开展系统设计与实现。《基于 Vue 和 Spring Boot 的 C 语言程序在线测评系统的设计与实现》一文中，通过构建在线编程与自动评测功能，实现了学生代码的即时评判与反馈，有效提升了程序设计教学的实践性和教学效率[3]。该研究表明，将在线评测系统引入日常教学，有助于培养学生的编程能力和自主学习能力。
　　此外，Spring Boot 在教学管理类系统中的应用也得到了广泛关注。《基于 Spring Boot 的课程评价系统设计与实现》中指出，采用模块化设计思想和分层架构，可以提高系统的扩展性和稳定性，为多角色教学系统的开发提供了可靠思路[4]。该研究为本课题中学生、教师和管理员多角色协同的系统设计提供了借鉴。
　　在程序设计评测的深入研究中，部分学者关注代码质量与相似度检测问题。范佳杰等人在《编程考试系统代码质量度量及相似度检测子系统的设计与实现》中，对编程考试系统中的代码评测与学术诚信问题进行了研究，为提升评测系统的客观性和公平性提供了技术支撑[5]。该研究为程序设计评测系统的后续功能扩展提供了理论基础。
　　尤枫等较早在《编译程序在线评测系统的实现》中对在线评测系统的核心技术进行了研究，提出了基于编译与运行机制的自动判题方法，为后续在线评测系统的发展奠定了基础[6]。该研究在在线评测系统发展初期具有重要的参考价值。
　　综上所述，现有研究从竞赛评测、教学应用、系统架构和评测机制等多个角度对程序设计在线评测系统进行了探索。基于 Spring Boot 技术构建一个集在线编程、自动评测、竞赛管理与教学辅助功能于一体的程序设计评测系统，具有明确的研究背景和较高的实际应用价值。

二、设计（论文）主要内容
　　本课题采用 Spring Boot 技术进行系统后端开发，数据库选用 MySQL，开发工具使用 IDEA 软件，前端采用 Vue 技术实现系统界面与交互功能。系统面向学生用户、教师用户和管理员三类角色，围绕程序设计教学与评测需求展开设计，实现一个完整的程序设计评测系统。
　　（1）针对学生用户的学习与实践需求，系统提供注册、登录和个人中心等基础功能。学生可在题库模块中浏览编程题目，在线编写并提交程序代码，系统将根据预设的测试数据自动进行编译、运行与评测，并将评测结果及时反馈给学生。同时，系统支持编程竞赛与排名功能，学生可参加竞赛并查看实时榜单及历史成绩；通过讨论区模块，学生可以进行问题讨论与经验交流，形成良好的学习社区氛围。
　　（2）针对教师用户的教学与管理需求，系统提供登录、题目管理、竞赛组织、结果查看与分析以及数据导出等功能。教师可自行设计并发布编程题目，设置题目描述、样例输入输出及多组测试数据；可创建并管理编程竞赛，设定竞赛时间、参赛题目和规则；并可实时查看学生成绩，对教学效果进行分析，同时支持将成绩与排名数据导出为 Excel 或 CSV 文件，便于后续教学评估。
　　（3）针对管理员用户的系统管理需求，系统提供登录、用户管理、题库管理、系统配置与日志管理等功能。管理员负责系统整体运行维护，进行学生信息维护、题目资源管理以及系统权限和运行状态监控，保障系统安全、稳定运行。
　　三、
设计（研究）方案
　　1. 需求分析
　　系统开发采用 B/S 架构模式，后端主要使用 Spring Boot 框架实现业务逻辑处理，前端采用 Vue 技术构建用户界面，数据库采用 MySQL 进行数据存储[8,9,10]。系统需满足程序设计教学中在线编程、自动评测、竞赛组织和学习交流等核心需求，并保证系统具有良好的安全性、稳定性和可扩展性。
　　2. 功能模块设计
　　（1）管理员模块
包括登录、个人信息管理、用户管理、题库管理、系统配置与日志管理等功能。管理员拥有系统最高权限，负责系统数据维护与运行监控。
　　（2）教师模块
包括登录、题目管理、竞赛管理、成绩查看与分析、数据导出等功能。教师可根据教学计划灵活组织教学内容与竞赛活动。
　　（3）学生模块
包括注册、登录、个人信息管理、题库练习、在线评测、竞赛与排名、讨论区交流等功能，满足学生自主学习与能力提升的需求。
　　3. 数据库设计
　　根据系统功能需求，初步设计数据库表包括：
学生用户信息表、教师用户信息表、管理员信息表、题目信息表、测试数据表、代码提交记录表、评测结果表、竞赛信息表、竞赛成绩表、讨论区帖子表等。
　　4. 系统测试
　　在系统开发过程中，对各功能模块进行单元测试，确保功能正确实现；系统开发完成后进行整体功能测试与性能测试，对发现的问题进行修改和优化。通过多轮测试，保证系统运行稳定、安全可靠，达到设计要求。
