# OnlineJudge 最小部署与演示文档（Windows 单机）

更新时间：2026-03-10  
适用目录：`D:\OJ-project`

## 1. 目标

用一台 Windows 机器，快速拉起可演示版本（前端 + 后端 + MySQL + Redis + Docker 判题），并完成答辩演示主链路：

1. 登录
2. 浏览题目
3. 提交代码并看到评测结果
4. 竞赛创建与报名
5. 管理后台查看系统配置/日志

## 2. 环境要求

1. JDK 17
2. Maven 3.8+
3. Node.js 18 LTS（npm 9+）
4. MySQL 8.0
5. Redis 6+
6. Docker Desktop（开启后端 Linux 容器）

快速检查命令（PowerShell）：

```powershell
java -version
mvn -version
node -v
npm -v
docker -v
```

## 3. 第一次部署（空数据库）

### 3.1 创建数据库

```sql
CREATE DATABASE IF NOT EXISTS onlinejudge
  DEFAULT CHARACTER SET utf8mb4
  DEFAULT COLLATE utf8mb4_unicode_ci;
```

### 3.2 初始化核心与扩展表

在 MySQL 客户端中依次执行（路径按你的本地目录修改）：

```sql
USE onlinejudge;
SOURCE D:/OJ-project/onlinejudge-backend/scripts/create_core_tables.sql;
SOURCE D:/OJ-project/onlinejudge-backend/scripts/create_discussion_tables.sql;
SOURCE D:/OJ-project/onlinejudge-backend/scripts/create_contest_tables.sql;
SOURCE D:/OJ-project/onlinejudge-backend/scripts/create_system_tables.sql;
SOURCE D:/OJ-project/onlinejudge-backend/scripts/create_judge_tables.sql;
SOURCE D:/OJ-project/onlinejudge-backend/scripts/create_role_profile_tables.sql;
SOURCE D:/OJ-project/onlinejudge-backend/scripts/add_core_indexes.sql;
```

说明：

1. `create_core_tables.sql` 已包含基础 4 表：`user`、`problem`、`test_case`、`submission`
2. 同时会创建管理员账号：
   - 用户名：`admin2`
   - 密码：`admin123`
3. 同时会插入一个 `A+B Problem` 题目，便于冒烟测试

## 4. 启动依赖服务

### 4.1 启动 Redis

确保 `localhost:6379` 可连接。

### 4.2 启动 Docker Desktop 并预拉镜像

```powershell
docker pull eclipse-temurin:17-jdk
docker pull gcc:13
docker pull python:3.11-alpine
```

## 5. 启动后端

### 5.1 检查配置

文件：`onlinejudge-backend/src/main/resources/application.yml`

重点确认：

1. `spring.datasource.url/username/password`
2. `spring.redis.host/port`
3. `server.port`（默认 `8082`）
4. `judge.sandbox.enabled`（建议本机演示保持 `true`）

### 5.2 启动

```powershell
cd D:\OJ-project\onlinejudge-backend
mvn spring-boot:run
```

后端接口根地址：`http://localhost:8082/api`

## 6. 启动前端

```powershell
cd D:\OJ-project\onlinejudge-frontend-v2
npm install
npm run dev
```

前端默认地址（Vite）：`http://localhost:5173`

当前开发环境下，前端会直接请求：`http://localhost:8082/api`  
配置文件：`onlinejudge-frontend-v2/.env`

## 8. 演示流程（答辩可直接照做）

建议 8-12 分钟版本：

1. 用 `admin2/admin123` 登录
2. 进入题库，打开 `A+B Problem`
3. 提交一份正确代码，展示结果从 `PENDING/JUDGING` 到 `ACCEPTED`
4. 打开提交详情，演示“重判（Rejudge）”
5. 进入竞赛页，创建一场含 1 道题的短时竞赛
6. 报名该竞赛，查看实时榜与快照榜
7. 进入系统管理页，展示系统配置、审计日志、评测结果列表

## 9. 常见故障与处理

### 9.1 8082 端口被占用

错误：`Port 8082 was already in use`

```powershell
netstat -ano | findstr :8082
taskkill /PID <PID> /F
```

### 9.2 Flyway 报 MySQL 不支持

错误：`Unsupported Database: MySQL 8.0`

处理：

1. 确认 `onlinejudge-backend/pom.xml` 已包含 `flyway-mysql`
2. 执行：

```powershell
cd D:\OJ-project\onlinejudge-backend
mvn -U clean package -DskipTests
```

3. 重新启动后端

### 9.3 比赛字段缺失

错误：`Unknown column 'scoreboard_freeze_time'` 或 `contest_participant.create_time`

处理：

```sql
SOURCE D:/OJ-project/onlinejudge-backend/scripts/create_contest_tables.sql;
```

### 9.4 管理员密码不匹配

处理：

```sql
SOURCE D:/OJ-project/onlinejudge-backend/scripts/create_admin2.sql;
```

或重新执行：

```sql
SOURCE D:/OJ-project/onlinejudge-backend/scripts/create_core_tables.sql;
```

### 9.5 重判接口 404

说明当前运行中的后端进程不是最新代码。  
处理：在 `D:\OJ-project\onlinejudge-backend` 重新 `mvn spring-boot:run`。
