# 平台对标改进优先级路线图（对标洛谷/力扣）

更新时间：2026-03-17
适用范围：`D:\OJ-project` 当前前后端代码

## 目标
在不盲目堆功能的前提下，优先补齐“判题可信度 + 学习闭环 + 竞赛体验 + 社区治理 + 工程稳定性”，将项目从“可用原型”提升到“高质量毕业设计”。

## P0（必须优先完成，直接影响项目可信度）

### P0.1 判题可解释性（进行中）
- [x] 后端错误信息增加测试点上下文（第几个点、样例/隐藏、输入预览）
- [x] WA 展示期望输出与实际输出预览
- [x] TLE/RE 展示对应测试点上下文
- [x] 前端“评测状态”错误详情改为多行可读展示（保留换行）
- [x] 新增“测试点明细表 + 状态接口返回 caseResults”支持逐点结果展示
- [ ] 下一步：补充测试点详情页（查看输入/期望/实际完整内容）

### P0.2 题库与测试数据质量
- [ ] 题目去重（标题+来源+内容特征）
- [ ] 测试数据覆盖率检查（边界/随机/极值/反例）
- [ ] 数据质量评分（低质量题目打标）
- [ ] 导入后自动质量报告（通过率异常、样例弱覆盖提醒）

### P0.3 判题稳定性与回归保障
- [ ] 判题链路冒烟脚本固定化（Java/C++/Python 各 3 题）
- [ ] 常见错误回归用例（WA/TLE/MLE/RE/CE）
- [ ] Docker 与本地 fallback 一致性检查

## P1（核心体验增强，形成平台差异化）

### P1.1 学习闭环（对标力扣）
- [ ] 题单/学习计划（按难度和标签分组）
- [ ] 用户做题进度（已做、已过、待补）
- [ ] 下一题推荐（同标签+难度渐进）

### P1.2 竞赛体验（对标洛谷）
- [ ] 虚拟参赛
- [ ] 赛后回放（提交时间轴）
- [ ] 封榜可视化与解榜过程
- [ ] 榜单导出（CSV）

### P1.3 社区质量治理
- [ ] 题解专区与普通讨论分区
- [ ] 举报/审核流程
- [ ] 优质帖置顶与作者标识
- [ ] 防灌水策略（频率限制+重复内容检测）
