## 5. 功能需求（按模块）

### 5.1 用户系统
- 功能点：
1. 注册（用户名/邮箱/密码）
2. 登录（JWT）
3. 登出
4. 修改资料
5. 修改密码

- 验收标准：
1. 注册成功后可登录
2. 未登录访问受保护页面自动跳转登录页
3. token 失效后自动退出并提示

### 5.2 题库系统
- 功能点：
1. 题目列表分页
2. 按难度/关键词筛选
3. 题目详情（描述、输入输出、样例）
4. 通过率/提交数展示

- 验收标准：
1. 列表支持分页与筛选联动
2. 打开题目详情无报错
3. 数据为空时有空状态提示

### 5.3 提交与评测
- 功能点：
1. 选择语言并提交代码
2. 返回提交ID
3. 轮询或推送评测状态（PENDING/JUDGING/AC/WA/TLE/RE/CE）
4. 查看执行时间、内存、错误信息

- 验收标准：
1. 提交成功后可在记录页看到该条记录
2. 评测状态可从等待变为终态
3. 错误信息可读、字段完整

### 5.4 提交记录
- 功能点：
1. 我的提交分页列表
2. 按题目/状态筛选（可选）
3. 提交详情页展示源码与评测结果

- 验收标准：
1. 列表与详情数据一致
2. 非本人无权查看他人私有记录（按规则）

### 5.5 题目管理（教师/管理员）
- 功能点：
1. 新建题目
2. 编辑题目
3. 删除题目（仅管理员）
4. 题目字段校验

- 验收标准：
1. 新增后在题库可见
2. 编辑后实时生效
3. 删除有二次确认与权限校验

### 5.6 用户管理（管理员）
- 功能点：
1. 用户列表分页
2. 角色查看/调整（可选）
3. 状态管理（封禁/解封，可选）

- 验收标准：
1. 非管理员无法访问
2. 修改用户角色后权限生效
