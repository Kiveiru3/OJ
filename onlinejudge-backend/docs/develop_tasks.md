# Online Judge v1.0 (MVP) 开发任务清单

## 1. 目标与边界
- 目标版本：`v1.0 (MVP)`
- 任务来源：`docs/develop.md`
- 本清单覆盖：用户系统、题库系统、提交评测、提交记录、后台管理、权限控制
- 本期排除：比赛系统、题单、讨论区/题解、排行榜、通知中心

## 2. 里程碑与顺序
1. `M0` 基础设施与项目骨架
2. `M1` 用户与权限（登录可用）
3. `M2` 题库与题目管理（题目可查可管）
4. `M3` 提交与评测链路（可提交并看到结果）
5. `M4` 提交记录与后台用户管理
6. `M5` 联调、测试、上线准备

## 3. 任务拆解（可直接建 issue）

### M0 基础设施与项目骨架
1. 建立统一配置
- 内容：多环境配置（dev/test/prod）、数据库连接、日志级别、跨域配置
- 产出：`application-*.yml` 或等价配置文件
- 验收：本地可启动，健康检查接口返回正常

2. 建立基础工程结构
- 内容：按模块分层（controller/service/repository/dto/entity）
- 产出：目录结构与基础模板代码
- 验收：新增模块时无需调整整体结构

3. 建立全局异常与统一返回体
- 内容：全局异常处理、返回格式 `code/message/data`
- 产出：统一响应组件
- 验收：常见异常可被统一处理并返回可读错误

4. 建立数据库迁移方案
- 内容：建表脚本、版本化迁移（如 Flyway/Liquibase）
- 产出：初始 migration
- 验收：空库可一键迁移到当前版本

### M1 用户与权限
1. 用户表与认证模型
- 内容：用户实体、角色枚举、状态字段（正常/封禁）
- 依赖：M0-4
- 验收：能持久化用户并支持角色区分

2. 注册接口
- 内容：用户名/邮箱唯一性校验、密码加密存储
- 验收：重复用户名/邮箱返回明确错误，注册成功可登录

3. 登录与 JWT 发放
- 内容：账号密码登录、签发 access token、过期策略
- 验收：登录成功返回 token，非法凭证被拒绝

4. 鉴权中间件与 RBAC
- 内容：受保护接口鉴权，按角色授权（游客/学生/教师/管理员）
- 验收：未登录访问受保护接口返回未授权，越权访问被拒绝

5. 个人信息与修改密码
- 内容：查询个人资料、修改资料、修改密码
- 验收：修改后重新查询可见变更，旧密码不可继续使用

6. 前端登录态管理
- 内容：登录页、token 存储、过期自动退出与提示
- 验收：token 失效自动跳转登录页

### M2 题库与题目管理
1. 题目数据模型
- 内容：题目基础字段、样例、时间/内存限制、可见性
- 依赖：M0-4
- 验收：题目数据可完整存取

2. 题目列表与筛选接口
- 内容：分页、关键词、难度筛选
- 验收：分页与筛选可组合使用，返回总数正确

3. 题目详情接口
- 内容：题面、输入输出说明、样例、统计字段
- 验收：打开任意有效题目无报错

4. 教师/管理员题目管理接口
- 内容：新建、编辑、删除（仅管理员）、字段校验
- 验收：教师可新建/编辑，删除需管理员且二次确认

5. 前端题库页面
- 内容：题目列表页、筛选栏、详情页、空状态
- 验收：空数据有提示，筛选与分页联动正常

### M3 提交与评测链路
1. 提交数据模型与接口
- 内容：提交记录表、提交代码接口、返回 submissionId
- 依赖：M1、M2
- 验收：提交成功后返回有效 ID 并写入数据库

2. 评测任务队列
- 内容：提交入队、判题 worker 消费、状态流转
- 验收：状态按 `PENDING -> JUDGING -> 终态` 转换

3. 判题执行器接入
- 内容：按语言执行（Java/C++/Python）、时空限制、结果归档
- 验收：至少 1 道样例题可跑通 AC/WA/TLE/RE

4. 评测状态查询（轮询或推送）
- 内容：前端轮询接口或 websocket 推送
- 验收：提交后前端可看到状态实时变化

5. 执行详情展示
- 内容：运行时间、内存、错误信息展示
- 验收：错误信息可读且字段完整

### M4 提交记录与后台用户管理
1. 我的提交列表与筛选
- 内容：按用户分页、按题目/状态筛选
- 依赖：M3
- 验收：仅返回当前用户可见记录

2. 提交详情接口
- 内容：源码与评测结果详情，权限校验
- 验收：非本人无法访问私有提交详情

3. 管理员用户列表
- 内容：分页查询用户、条件过滤
- 验收：非管理员不可访问

4. 角色调整与状态管理（可选）
- 内容：调整角色、封禁/解封
- 验收：角色变更后权限即时生效

5. 前端后台管理页面
- 内容：用户管理页、题目管理页
- 验收：核心管理操作可在 UI 完成

### M5 联调、测试、上线准备
1. API 联调与错误码对齐
- 内容：前后端字段、状态码、错误提示统一
- 验收：联调清单全部通过

2. 自动化测试
- 内容：核心服务单测、关键接口集成测试、权限测试
- 验收：核心路径测试通过率 100%

3. 安全与稳定性检查
- 内容：SQL 注入、越权、限流、密码策略、日志脱敏
- 验收：高风险项全部关闭

4. 发布准备
- 内容：部署脚本、环境变量清单、回滚方案、监控告警
- 验收：可按文档完成一次演练发布

## 4. 任务依赖图（简版）
- `M0 -> M1 -> M2 -> M3 -> M4 -> M5`
- `M3` 依赖 `M1`（用户鉴权）与 `M2`（题目存在与限制）
- `M4` 依赖 `M3`（提交数据已生成）

## 6. 建议优先级（P0）
1. 用户注册/登录/JWT 鉴权
2. 题目列表/详情
3. 提交接口与评测状态流转
4. 我的提交列表与详情权限校验
5. 题目管理（教师编辑、管理员删除）

## 7. 完成定义（DoD）
- 功能可在前端页面操作并走通主流程
- 接口文档已更新，字段与错误码说明完整
- 至少包含：正常路径、参数错误、权限错误 3 类测试
- 关键操作有日志，敏感信息不明文输出
- 验收标准与 `docs/develop.md` 对齐
