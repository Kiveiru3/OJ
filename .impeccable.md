## Design Context

### Users
- Primary users are students, teachers, and administrators using an online judge for practice, teaching, contests, and discussion.
- This interface is used inside a logged-in product workflow, not on a marketing page.
- The personal settings page should help users quickly update the few pieces of information that affect community display and account management.

### Brand Personality
- Calm
- Efficient
- Academic

The product should feel trustworthy, restrained, and practical. It should support frequent use without visual fatigue.

### Aesthetic Direction
- Stay aligned with the existing product language: white cards, light neutral backgrounds, clear borders, modest radii, and understated hierarchy.
- Prefer a "small and refined" control-panel feel over expressive hero sections or showcase layouts.
- Avoid visual noise, decorative gradients, oversized metrics, nested cards, or heavy marketing-style presentation.

### Design Principles
- Prioritize task completion over decoration.
- Keep the hierarchy obvious with spacing and typography, not extra containers.
- Use only a few visual emphasis points and let the rest recede.
- Reduce repetition: do not restate information the user can already see.
- Match the existing OJ product shell instead of introducing a separate visual language.
